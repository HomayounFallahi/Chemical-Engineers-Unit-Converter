## ✨ Features

- **20+ unit categories**: length, weight, volume, pressure, temperature, flow rates, viscosity, energy, duty, density, etc.
- **gauge vs. absolute conversion**: Handles °F/°C/K/R and gauge vs. absolute pressure correctly.
- **Flow Rate Equivalence Calculator**: Convert between **mass**, **volumetric**, and **molar** flow rates with automatic prompts for density or molar mass when needed.
- **Bulk conversion**: Instantly see conversions to all units in the current category.
- **Dark/Light mode**: Toggle with a switch; remembers your preference via `localStorage`.
- **Fully responsive**: Works on mobile, tablet, and desktop.
- **Offline capable**: Runs entirely in the browser—no internet or server required.

## 🚀 How to Use

1. **Open the app** in any modern browser (Chrome, Firefox, Edge, Safari).
2. **Select a category** (e.g., *Pressure*, *Flow Rate*, *Temperature*) from the tabs.
3. **Enter a value** in the "From" field.
4. **Choose input and output units** from the dropdowns.
5. **See the result instantly**—no "Convert" button needed!
6. (Optional) Click **"Flow Rate Equivalence Calculator"** to convert between different flow rate types (mass ↔ volumetric ↔ molar).

> 💡 **Tip**: Use the **swap button** (🔄) to quickly reverse the conversion direction.

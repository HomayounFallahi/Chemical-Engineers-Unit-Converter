## ✨ Features

### Core Unit Conversion
- **34 unit categories**: length, weight, volume, pressure, temperature, flow rates (mass/molar/volumetric), viscosity (dynamic & kinematic), energy, duty, density, thermal properties, concentrations, electrical units, and more
- **Temperature & gauge pressure handling**: Correctly converts °F ↔ °C ↔ K ↔ R and gauge vs. absolute pressure
- **Bulk conversions**: Instantly see all equivalent units in the current category
- **Adjustable precision**: Choose significant figures (4–12 digits) for display

### Discovery & Search
- **Quick-jump search bar**: Type any unit name or category to navigate instantly (e.g., "psi", "viscosity", "kW") — no tab hunting
- **Clear category tabs**: All common units on one row; additional categories in a collapsible menu
- **Gas constant reference panel**: One-click access to the universal gas constant (R) in 13+ different unit systems

### Flow Rate Tools
- **Flow Rate Equivalence Calculator**: Convert between **mass**, **volumetric**, and **molar** flow rates
- **Smart property detection**: Automatically prompts for density or molar mass only when needed
- **Quick-fill substance presets**: One-click fill for common materials (water, air, ethanol, steam, CO₂, methane) with known density & molar mass
- **No manual lookups**: Skip the reference tables—tap a preset and convert

## 🚀 How to Use

### Basic Conversion
1. **Open the app** in any modern browser (Chrome, Firefox, Edge, Safari)
2. **Select a category** from the tabs (e.g., *Pressure*, *Flow Rate*, *Temperature*)
3. **Enter a value** in the "From" field
4. **Choose input and output units** from the dropdowns
5. **See the result instantly** — displayed on the digital readout
6. *(Optional)* Click the **swap button** (⇅) to reverse the direction

> **💡 Tip**: Use the search bar to jump straight to a unit. Type "psi", "kW", or "viscosity"—the app finds it for you.

### Flow Rate Conversions
1. Click **"Flow Rate Equivalence"** button in the header
2. Select **From** type (Mass / Volumetric / Molar) and unit
3. Select **To** type and unit
4. If converting between different types (e.g., vol → mass), the app auto-prompts for **density** or **molar mass**
5. Click a **quick-fill preset** (e.g., "Water (l)") to auto-populate properties, or enter custom values
6. Click **Calculate** to get the result

### Checking Your History
1. Click the **History** button in the header
2. Your last 12 conversions appear in reverse chronological order
3. Click any entry to restore it instantly (units and values reload)
4. Click **Clear** to reset the history


### Known Limitations
- **Theme persistence**: On this preview version, dark mode doesn't persist across browser sessions (localStorage not available). On a self-hosted version, your preference is saved.
- **Precision**: Limited to JavaScript's floating-point precision (~15 significant figures). Exponential notation used for very large/small numbers.
